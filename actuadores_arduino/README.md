# actuadores_arduino

Esta carpeta contiene el firmware del robot mBot para controlar motores.

## Placa usada

El codigo esta pensado para Arduino Uno (mBot / mCore compatible con el entorno Arduino).

## Archivo principal

- arduinoFinal.ino

## Regla para estudiantes

No modificar esta carpeta durante los retos.

Solo debe cargarse el firmware en el robot y dejarlo fijo para que el control se haga desde el Master PC.
